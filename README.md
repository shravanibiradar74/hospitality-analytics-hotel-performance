# 🏨 Hospitality Analytics – Hotel Performance Analysis

## 📌 Project Overview

Hospitality Analytics is a team-based data analytics project focused on analyzing hotel performance using **Excel, SQL, Power BI, and Tableau**.

The project analyzes hotel revenue, bookings, occupancy, cancellations, room classes, cities, hotels, and weekly performance trends. The main goal is to convert raw hospitality data into meaningful KPIs, visualizations, and business insights.

## 🎯 Project Objectives

- Analyze hotel revenue and booking performance.
- Measure occupancy and cancellation rates.
- Compare performance across hotels, cities, and room classes.
- Analyze weekday vs. weekend performance.
- Identify weekly revenue and booking trends.
- Calculate important hospitality KPIs using SQL.
- Build interactive dashboards using Power BI and Tableau.
- Present meaningful business insights through data visualization.

## 🛠️ Tools & Technologies

- **Microsoft Excel** – Data preparation, analysis and dashboard
- **MySQL / SQL** – Data management, queries and KPI analysis
